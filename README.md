# Анализ данных ДТП — проект «Карта ДТП»

Учебный исследовательский проект по анализу данных о дорожно-транспортных происшествиях  
в России. Заказчик — некоммерческий проект **«Карта ДТП»**, цель которого повысить  
безопасность на дорогах, выявлять реальные причины аварий и разрабатывать программы  
по улучшению дорожной инфраструктуры.

## Задачи исследования

### Предобработка данных
1. Привести названия столбцов к удобному для работы виду.
2. Проверить пропуски в данных. Изучить, в каких столбцах они встречаются,  
   предположить причины возникновения и дать рекомендации заказчику.
3. Проверить явные и неявные дубликаты. Оценить их долю в данных.

### Исследовательский анализ
1. Определить, сколько ДТП происходит в каждый день недели и по месяцам.
2. Выделить категории водителей по стажу и определить, какие категории  
   значительно отличаются по числу ДТП.
3. Проанализировать динамику числа аварий по годам в **Кировской**  
   и **Московской** областях (с включением г. Киров в Кировскую область и исключением  
   Москвы из Московской). Сравнить число аварий на 100 000 жителей.
4. Исследовать связь категорий аварий и погодных условий.
5. Построить процентную разбивку аварий по видам освещённости  
   в разрезе пола участников.
